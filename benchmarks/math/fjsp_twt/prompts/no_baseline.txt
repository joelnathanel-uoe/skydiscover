You are an expert in combinatorial optimization and scheduling. Your task
is to write a heuristic for the Flexible Job Shop Scheduling Problem with
Total Weighted Tardiness (FJSP-TWT).

--- The problem ---

n jobs and m machines. Each job is a fixed sequence of operations; each
operation must run on one of its eligible machines without preemption. A
job's operations must run in order — operation k cannot start until
operation k-1 ends. Minimise total weighted tardiness:
  TWT = sum_j  w_j * max(0, C_j - d_j)
where w_j is the job weight, d_j its due date, C_j its completion time.

--- What your function must do ---

Implement schedule_next. Each call, it selects one unscheduled operation,
assigns it to an eligible machine, and places it in that machine's queue:

    def schedule_next(unscheduled, machine_sequences, start_times, end_times,
                      job_completion, instance):
        ...
        return op, machine, position

Each call you return three things:
  op       — (j, o): which operation to place. Must be in unscheduled.
               (j, o) is ready to place if o == 0 or (j, o-1) is placed.
  machine  — which machine to assign it to (must be eligible for that op).
  position — where in machine_sequences[machine] to insert it:
               == len(seq): append at end — always feasible.
               <  len(seq): insert before that index, shifting later ops
                            back. Invalid if it creates a job-precedence
                            cycle — the program is rejected.

The state you have access to:
  unscheduled       set[(j, o)] — ops not yet placed
  machine_sequences dict[m -> list[(j, o)]] — each machine's queue
  start_times       dict[(j, o) -> int] — exact if placed; lower bound if not
  end_times         dict[(j, o) -> int] — exact if placed; lower bound if not
  job_completion    dict[j -> int | None] — completion of j's last op, or None
  instance          n_jobs, n_machines, jobs[{release_time, due_date, weight,
                      operations: [[[machine_id, proc_time], ...], ...]}]

--- Scoring ---

Your function will be called repeatedly to build a complete schedule. Once
all operations are placed, total weighted tardiness is computed as:

  TWT = sum_j  w_j * max(0, C_j - d_j)

where C_j is the completion time of job j's last operation, d_j is its due
date, and w_j is its weight. A job that finishes on time contributes 0;
one that finishes late contributes w_j * (C_j - d_j).

We score your function by running it on 100 benchmark instances and taking
the median TWT. Your aim is to minimise this — the lower the better. If your
function produces an invalid schedule or times out on any instance, the entire
program is invalid.

Restrictions: Python standard library + numpy only.
